# Sonora

Открытая модификация Яндекс Музыки для Windows и лаунчер установки.

## Возможности

- Обои из изображений, GIF, видео и YouTube.
- Акцент интерфейса и NCS с анализом частот звука.
- Синхронизированные тексты с проявлением букв.
- Редактор раскладки и материалов.
- 16 наборов иконок и управление в эскизе окна Windows.
- Установка и восстановление оригинального клиента через лаунчер.

## Сборка

Нужны Windows x64, Node.js 22+ и .NET Framework 4.8.
Эта версия совместима с официальным клиентом 5.127.0.

1. Получите официальный клиент Яндекс Музыки 5.127.0 и его официальный установщик.
2. Создайте папку `studio-official` рядом с исходниками. Скопируйте туда оригинальные `Яндекс Музыка.exe` и `resources/app.asar` (как `app.asar`).
3. Создайте папку `pulsesync-rollback` и положите туда установщик `Yandex_Music_x64_5.127.0.exe`. Это служебное имя папки совместимости сборки.
4. Выполните `powershell -ExecutionPolicy Bypass -File ./build.ps1`.
5. Результат появится в `bin/Sonora-Launcher.exe`.

Сборка проверяет подпись установщика. Проверяйте происхождение входных файлов.
Готовый лаунчер содержит входной установщик и архивы клиента. Перед распространением проверьте права на распространение компонентов Яндекса.

MIT распространяется на собственные исходники Sonora. Яндекс Музыка является продуктом Яндекса и используется по его условиям.

## Установка

Закройте Музыку, включая значок в трее. В лаунчере выберите установку Sonora.
Модификация меняет архив приложения и хэш архива в EXE. Подпись изменённого EXE становится недействительной.
Обновление Музыки может заменить мод. Неизвестные версии лаунчер отказывается модифицировать.
Для возврата используйте «Вернуть оригинал».

## Проверки и ограничения

Проверены установка, повторная установка, обновление и точный откат на копиях файлов.
Интерфейс проверялся автоматически в Electron. Отдельный чистый ПК целиком не проверялся.
Проявление букв распределяется по длительности строки. Для YouTube требуется доступность сервиса и разрешение встраивания.
NCS подключается к Web Audio графу клиента. Новые версии Музыки требуют адаптации патчера.

## Данные

Настройки хранятся в локальном профиле Музыки. В репозитории находятся исходники Sonora.
