# Sonora

Открытая модификация Яндекс Музыки для Windows и лаунчер установки.

## Возможности

- Обои из изображений, GIF, видео и YouTube.
- Акцент интерфейса и NCS с анализом частот звука.
- Синхронизированные тексты с проявлением букв.
- Редактор раскладки и материалов.
- Скрытие отдельных вкладок бокового меню.
- Discord Rich Presence с треком, исполнителем, обложкой и временем воспроизведения.
- 16 наборов иконок и управление в эскизе окна Windows.
- Установка и восстановление оригинального клиента через лаунчер.
- Проверка обновлений Sonora на GitHub при запуске лаунчера и входе в Windows.

## Сборка

Нужны Windows x64, Node.js 22+ и .NET Framework 4.8.
Эта версия совместима с официальным клиентом 5.128.0.

1. Получите официальный клиент Яндекс Музыки 5.128.0 и его официальный установщик.
2. Создайте папку `studio-official` рядом с исходниками. Скопируйте туда оригинальные `Яндекс Музыка.exe` и `resources/app.asar` (как `app.asar`).
3. Создайте папку `pulsesync-rollback` и положите туда установщик `Yandex_Music_x64_5.128.0.exe`. Это служебное имя папки совместимости сборки.
4. Выполните `powershell -ExecutionPolicy Bypass -File ./build.ps1`.
5. Результат появится в `bin/Sonora-Launcher.exe`.

Сборка проверяет подпись установщика. Проверяйте происхождение входных файлов.
Готовый лаунчер содержит входной установщик и архивы клиента. Перед распространением проверьте права на распространение компонентов Яндекса.

MIT распространяется на собственные исходники Sonora. Яндекс Музыка является продуктом Яндекса и используется по его условиям.

## Установка

Закройте Музыку, включая значок в трее. В лаунчере выберите установку Sonora.
Модификация меняет архив приложения и хэш архива в EXE. Подпись изменённого EXE становится недействительной.
Обновление Музыки может заменить мод. Неизвестные версии лаунчер отказывается модифицировать.
Для перехода с Sonora для Музыки 5.127.0 обновите саму Музыку до 5.128.0, затем установите Sonora этой версии. Если обновление не запускается, верните оригинальные файлы прежним лаунчером и повторите обновление Музыки.
Для возврата к оригинальной Музыке 5.128.0 используйте «Вернуть оригинал».

В **Sonora → Раскладка → Открыть редактор раскладки → Вкладки сайдбара** можно убрать ненужные пункты. «Готово» сохраняет выбор, «Отмена» возвращает предыдущую раскладку.

## Discord Rich Presence

Создайте приложение в [Discord Developer Portal](https://discord.com/developers/applications), например с названием Sonora, и скопируйте его Application ID. Введите его в **Sonora → Discord**, включите показ трека и разрешите показ активности в настольном Discord.

Sonora передаёт настольному Discord название трека, исполнителя, обложку и время начала и конца через локальное подключение RPC. Discord оформляет карточку и полоску времени на своей стороне. На паузе Sonora убирает активность. По умолчанию интеграция выключена.

## Обновления лаунчера

После первого запуска лаунчер добавляет фоновую проверку в автозагрузку текущего пользователя Windows. При входе в Windows окно откроется, если вышел новый релиз. Автозапуск можно отключить флажком «Проверять при входе в Windows». Если перенесли EXE, запустите его по новому пути.

Кнопка «Открыть релиз» ведёт на GitHub. Публичные релизы содержат исходники и инструкцию сборки. Версия лаунчера задаётся в `target.json` и сравнивается с тегом стабильного релиза в формате `v1.1.0`.

## Проверки и ограничения

Проверены установка, повторная установка и точный откат на копии клиента 5.128.0.
Проверен запуск 5.128.0 с тестовым профилем, загрузка настроек Sonora и подключение управления на панели задач. Воспроизведение с аккаунтом и синхронизация текста на треке требуют отдельной проверки.
Проявление букв распределяется по длительности строки. Для YouTube требуется доступность сервиса и разрешение встраивания.
NCS подключается к Web Audio графу клиента. Новые версии Музыки требуют адаптации патчера.

## Данные

Настройки хранятся в локальном профиле Музыки. В репозитории находятся исходники Sonora.
